# kaban

## Overview
Brand identity, typography studies, logo exploration rounds, and production vector/raster/web asset builders for Kaban and its Baulito chest companion. Contains the approved production kit (`logo-kit`) alongside earlier font comparisons and symbol concept rounds, plus the packaged archive `kaban-logo-kit.zip`.

## Subdirectories & Boundaries
- `baulito-logo-concepts`: [./baulito-logo-concepts/README.md](./baulito-logo-concepts/README.md) - Explores three Baulito mascot concepts and pairs `*-v2.svg` symbols with `public/kaban-wordmark-black.svg` via `build_lockups.py`.
- `chest-round`: [./chest-round/README.md](./chest-round/README.md) - Chest-reference symbol exploration (`seed-keeper`, `carved-seal`, `folded-guardian`) and Bantayog lockup generation via `build.py`.
- `font-study`: [./font-study/README.md](./font-study/README.md) - Outlines five local font families from `public/fonts/` into vector paths and generates 15 concept lockups plus `kaban-font-comparison.svg` via `build.py`.
- `logo-kit`: [./logo-kit/README.md](./logo-kit/README.md) - Builds and verifies the approved Baulito Curious Chest masters, multi-color SVG/PNG/web icon deliverables, contrast checks, and `public/` asset parity via `build.py` and `verify.py`.
